# ターコイズ不動産土地活用フォト サンプル画像

このフォルダには、SKILLの再現性を上げるための画像サンプルを入れています。

- `sample_full_lp_preview.jpeg`: 完成LP全体の縮小プレビュー
- `sample_hero.jpeg`: ファーストビューのサンプル
- `lp_01_hero_background.png`: ボタンを重ねる前の背景PNGサンプル
- `lp_01_hero_button.png`: CTAボタン単体の背景透過PNGサンプル
- `background_sample.png`: 背景PNGサンプルの別名
- `button_sample.png`: ボタン透過PNGサンプルの別名

生成時は、`sample_full_lp_preview.jpeg` と `sample_hero.jpeg` で全体のデザイン文法を確認し、ボタンを分けたい場合は `lp_01_hero_background.png` と `lp_01_hero_button.png` の考え方を参考にしてください。
