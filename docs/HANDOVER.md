## 4. 触る前に知るべき「理由のある設定」

1. **入札の上限CPC ¥650は外さない** — 上限¥2,500だった8/19、除外強化の反動でCPCが¥772まで暴騰・1日¥12,396消化した実績あり(クリック数最大化が予算消化のため単価を吊り上げる)。外すと再発する
2. **広告スケジュールは「作った時間帯しか配信されない」** — 行を削除すると配信停止になる。全曜日4枠(0-1時-30%/1-6時-60%/6-22時±0/22-24時-30%)が正しい状態
3. **除外してはいけない語**: 「事件現場特殊清掃センター」(CV実績あり)/買取系(クライアント確認中)/特掃専業競合の指名(特殊清掃いちばん・武蔵シンクタンク・アイコム・ビークリーン)
4. **広告グループ「遺品整理_一般」は停止中** — 削除も再開もしない(クライアント方針転換時のみ)
5. **GTMを再導入しない** — 計測は`components/mcy/McyTracking.tsx`のgtag直送信(line_click/phone_click)。GTM併用は二重計測になる
6. **LPデザイン**: 緑×金は5視点レビューで維持確定(2026-08-17)。赤の電話ボタンは緊急系の定石。全面刷新はクライアントが拒否済み — セクション単位・承認制で改善
