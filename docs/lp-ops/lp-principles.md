# クリックされ、読まれるLPの基準書（セレンシア）

- 版: v1（2026-10-07）。全エージェントが改善案を出すときの採点基準。月次ふりかえりで改訂する
- 上位の方針: `strategy.md`（誰に・何を・どの順番で）、`operating-plan.md`（報酬条件と体制）
- ゴール: 広告をクリックした人が **読み → 信じ → 連絡する**。成果指標は「広告経由の有効問い合わせ」

## 0. 測る指標（上から順に効く）

| 段階 | 指標 | 今の値（2026-10） | 目標 |
|---|---|---|---|
| 表示される | 検索インプレッションシェア／順位不足による損失 | 約50%／約40% | 70%／20%以下 |
| クリックされる | 広告CTR、推定CTR（品質スコアの要素） | 主力KWで推定CTR「平均より下」 | 「平均」以上 |
| 着地の質 | LPの利便性（品質スコアの要素）、表示速度（LCP） | 主要KWすべて「平均より下」、LCP 4〜10秒（遅い回線想定） | 「平均」以上、LCP 2.5秒以内 |
| 読まれる | スクロール到達率、セクション到達率、デッドクリック | Clarity・GA4で計測開始（10/1〜） | 料金事例まで50%以上 |
| 連絡される | 電話・LINEタップ率 | 0.84%（9月） | 1.5% |
| 成果 | 広告経由の有効問い合わせ／CPA | 確定0件 | 月12件／3万円以下 |

品質スコアが上がるとクリック単価が下がり、同じ予算でクリックが増える。**「クリックされる」と「着地の質」は、問い合わせ数とCPAの両方に効く最優先項目。**

## 1. クリックされる（広告）

- **検索意図と見出しを一致させる。** 費用系（費用・相場・値段）には総額の目安と事例価格、緊急系には「最短即日・今日相談できる」、法人系（管理会社・原状回復）には工程・報告・速さ
- **広告の約束 = LPのファーストビュー。** 広告で言ったことが、LPの最初の画面で確認できること（メッセージの一致）。一致しないと「LPの利便性」が下がり、離脱も増える
- **数字は最新・根拠ありだけ。** 口コミ件数は実数（自動連動）、「実績◯件」は根拠が確認できるまで使わない
- 地域名（東京・神奈川）と専門性（特殊清掃専門）を見出しに入れる。最上級表現・保証表現は使わない

## 2. 読まれる（LP）

1. **速さ:** 最初の画面が2.5秒以内に出ること。メイン画像は先読み、画面外の画像は遅延、焼き込み画像を減らす
2. **5秒で分かるファーストビュー:** 誰の（孤独死・事故現場の）、何を（臭い・汚染を）、いくらで（事例の総額）、いつ（最短即日）、どう連絡するか（電話・LINE）
3. **流し読みできる構造:** 見出しで結論を言う／1ブロック1メッセージ／1文はおおむね40字以内／箇条書きと太字／本文16px・注記14px以上
4. **不安を先回りする順番:** 当てはまるか → いくらか → 誰が・どこまで → 信頼できるか → どう連絡するか（`strategy.md` §3）
5. **各セクションの終わりに次の行動:** 読み終えた場所で電話・LINE・該当事例へ進める
6. **読まれていない兆候を毎週見る:** 到達率が急に落ちるセクション、押せない場所へのクリック（デッドクリック）、すぐ戻る動き

## 3. 視覚的要素

| 要素 | 役割 | 基準 |
|---|---|---|
| 実写（代表・スタッフ・現場） | 「この人が来る」安心 | 顔が見える。作り物の素材写真は使わない |
| 料金事例カード（総額・内訳・実写） | 「いくら」に答える | 似た状況から選べる。価格は事例データと一致 |
| 施工前後の写真 | 技術の証拠 | 配慮して加工。キャプションで状況を説明 |
| 口コミ（実在・日付つき） | 第三者の証拠 | 特殊清掃の口コミを先頭に。件数はGoogleと連動 |
| 資格・保険の証拠 | 信頼 | 名称を正確に。画像は補助 |
| アイコン・装飾 | 補助のみ | 情報を持たない装飾は減らす |
| 色 | 青テーマ＋電話は赤・LINEは緑 | CTAの色を他の要素に使わない |

## 4. 文章

- **共感 → 解決 → 証拠 → 行動** の順。最初の一文で読み手の状況を言い当てる
- ペルソナ別の言葉: 遺族には「突然のことで何から」「立ち会い不要」、管理会社には「工程」「報告」「原状回復まで」「近隣対応」
- 削る: 根拠のない数字、抽象語（丁寧・安心だけの文）、誰にも刺さらない要素（`strategy.md` のPOI）
- 事実（電話番号・受付時間・件数・価格・保証）は確認済みのものだけ

## 5. キービジュアル（ファーストビュー）

- **5秒テスト:** 初めて見た人が5秒で「何の会社か・いくらか・どう連絡するか」を言えること
- 構成: 代表の顔写真 ＋ 約束1つ（特殊清掃専門・最短即日）＋ 料金の目安 ＋ 電話・LINEの2ボタン
- **画像への文字の焼き込みを減らし、HTMLで組む。** 理由: 速度、文字の大きさ・読みやすさ、数字の自動更新（口コミ件数など）、A/Bテストができる
- 検索意図別のファーストビュー（費用重視／緊急／法人）を作り、広告グループごとに出し分けて比べる（メッセージの一致）

## 6. 改善の回し方

- 毎日: 計測・点検・広告の除外・実装PR（1日1件まで）
- 毎週: クリエイティブ監査（本基準で採点）、広告文の改善案、競合の変化、承認された1件を反映
- 毎月: エージェントの提案の当たり外れを振り返り、本基準と頻度を見直す
- 判定: 2週間以上かつ300クリック以上。タップ率は非劣性の確認に使い、勝ち負けは有効問い合わせとセクション到達率で見る
- **大胆な変更（ファーストビューの作り替えなど）はA/Bテストで比べてから全体に出す**
