# セレンシア: 月30成約戦略の目的

調査日: 2026-09-07 / project: P-9 / commander: ag-301 / task: T-87

## 目的

特殊清掃LPとGoogle検索広告を起点に月30件以上の成約を獲得するため、現状の強弱・競合・隣接業界を調べ、採る戦略と検証順序を明確にする。

ユーザーが「成約」と回答したため、最終KPIは月30成約と確定した。旧版の月30有効問い合わせという仮定は撤回する。計画上は、対応地域内の特殊清掃案件で契約成立が確認できるものを案件ID単位で数え、キャンセルは別記して純成約数を補正する。同一案件の電話・LINE再連絡、特殊清掃と遺品整理のセット内訳を別成約として水増ししない。

有効問い合わせは「対応地域内の特殊清掃について、双方向の相談が成立した新規案件」という中間KPI。営業・求人・誤電話は除外する。広告起点・紹介・自然検索を区別し、後二者を広告の成約実績に合算しない。契約成立日での月次件数と、問い合わせ発生月ごとの後日成約率を分けて集計する。

## 前提と制約

- 広告予算は引き継ぎ資料の月25万円を仮置き。最新の予算承認・問い合わせ数・成約率は未確認。
- 主軸は孤独死・事故現場の特殊清掃。一般遺品整理の集客再開は既存方針に反するため提案の主軸にしない。
- LP掲載地域は東京・神奈川。具体的な出動可能地域と遠方費用は事業者確認が必要。
- 調査と戦略文書を作成する。広告設定・本番LP・デプロイ・営業連絡は実施しない。
- 既存の緑・金のデザイン、上限CPC650円、GTMを再導入しない方針を引き継ぐ。変更の必要性があれば別途判断材料を示す。
- 既存レポートは二次資料として扱い、今回APIの生データを再取得できたとは記載しない。

## 進め方と完了条件

1. Intent: 目標、CV定義、費用・対応地域の前提を記録する。
2. Investigate: 既存実績とLP実装・本番表示、競合5社と隣接領域を検証する。
3. Spec: 月30成約の条件、必要相談数と成約率、広告・LP・受付・見積営業・施工体制の改善案、90日計画と実施タスクの受入基準を定義する。
4. 独立レビュー: 数式、出典、期間の混同、仮説の断定、既存方針との衝突を確認する。

専用の /intent・/investigate・/spec スキルはこの環境で確認できなかったため、同じ段階をこの3文書で明示する。T-87は分析の管理用であり、実装タスクは仕様化後に登録する。

## 未確定事項

- 月30成約の達成期限。
- 直近の有効問い合わせ件数、見積数、成約数、平均受注額、案件別粗利。
- 月額予算25万円が現在も有効か。運用・制作費を含むか。
- 正式な対応範囲、電話応答率、営業時間外のLINE返信体制、月間施工能力。
- Google Adsの再認証または対象アカウントの最新エクスポート。
