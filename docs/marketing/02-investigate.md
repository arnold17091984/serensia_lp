### 既存報告の判断で訂正すべき点

1. **遺品整理への浪費が継続しているとは言えない。** 引き継ぎでは8/18停止、8/24-30の週次は費用0。8月全体の27.6%を9月にも流出していると解釈しない。
2. **金曜への集中配信は根拠不足。** 全6タップ中4件という小標本から曜日・時間帯を過度に絞ると、偶然への最適化になる。まず受付可能時間と有効問い合わせの実績を見る。
3. **除外だけでは30件に届かない。** 月次の即時除外候補8,824円は総費用の約3.2%。候補の意図判定自体も再確認が必要。「誰が払う」は依頼直前の費用負担確認である可能性がある。
4. **競合指名は一括除外しない。** 専業競合指名を残す既存方針がある。求人などと分け、実問い合わせで評価する。「事件現場特殊清掃センター」等の既存CV語を資格関連というだけで除外しない。
5. **日次上限内でも月予算の整合確認が必要。** 9/1時点の設定は日予算15,000円と報告されている。一定で維持すれば標準的な月額換算は456,000円。月25万円なら平均日予算は約8,224円。月途中の変更や他キャンペーンを含めて予算レポートを再確認する。[Googleの予算仕様](https://support.google.com/google-ads/answer/6385083?hl=ja)
6. **予算損失とランク損失を区別する。** 9/1の報告は予算による損失IS0%、ランクによる損失IS62.6%。1日の値なので構造的結論は出せないが、増額だけが解決策という根拠にもならない。

### 9月データと計測

9/7の日次・週次報告は9/2以降の取得障害を `invalid_grant` と記録している。これはレポート取得の欠測であり、広告配信停止・CVゼロを意味しない。今回認証障害をAPIで再現したわけではない。再認証または管理画面のエクスポートで9月分を遡及集計する。

8/24引き継ぎでは通話計測が未着手。一方、現行 `app/layout.tsx` はGoogle Adsの転送電話番号設定を含み、9/1の設定報告も30秒通話に言及。したがって「通話計測を新規作成」ではなく、既存アクションの発火・電話番号差し替え・実通話の記録・Primary/Secondary・重複を確認する。[Googleの通話計測](https://support.google.com/google-ads/answer/6095883?hl=ja)

## 4. LPの強みと弱み

| 項目 | 確認した事実 | 戦略的評価・次の検証 |
|---|---|---|
| 対象の明確さ | 孤独死・事故現場、東京・神奈川、最短即日で現地確認 | 検索意図に合う。即日「完了」と誤解させない |
| 人と安心材料 | 代表紹介、資格、賠償責任保険、立ち会い不要、近隣配慮 | 保持。担当者と完了報告までの責任範囲を具体化 |
| CTA | 電話9-21時、LINE24時間受付、追従CTA、料金アンカー | 入口は存在。無応答・LINE追加後の未送信を測る |
| 工程 | 汚染建材撤去、消臭、コーティング、原状回復の説明 | 工程の列挙から「対象現場に何が必要か」に接続する |
| 実績 | 料金付き6事例、実写、作業内訳 | 強い資産。代表事例を料金検索者が早く読める位置へ |
| 価格 | 50,000円から。事例は15万・20万・22万・33万・38万・46万円 | 最低額と総額の差を説明。5万円の適用範囲、撤去・処分・原状回復の含有、税込/税別を明確化 |
| 口コミ | 5.0/167件を固定表示、掲載5件の内容は遺品整理中心 | 接遇の裏付けにはなるが特殊清掃の性能証拠ではない。最新件数・引用元・掲載時点も照合 |
| LINE | 写真なしOKの説明はあるが、ボタンは写真送付を強調。文例は実家の遺品整理 | 「写真がなくても相談可」をCTAで確認できるようにする。特殊清掃の文例に合わせる |

| 技術根拠 | 特許取得水系消臭や再発防止を掲載 | 使用製品・特許との関係・施工条件を示し、写真では分からない臭気の完了確認を説明 |
| 保証 | 賠償責任保険の説明あり | 消臭再施工保証とは別。保証を追加する場合は実運用・条件・費用を先に決める |
| 連絡の整合性 | FAQはメール24時間受付に言及、主導線は電話とLINE | メールの入口・返信運用が実在するか確認 |
| 他の自社サイト | `serenshia.com/tokusou/` は不定休、広告LPは年中無休 | 実態と統一。別サイトに法人入口が既にあるため新設前に内容確認 |

## 6. 業界構造と隣接業界

警察庁の2025年統計は、自宅で死亡した一人暮らしの者76,941人を報告している。これは特殊清掃の発注数でも、孤立死だけの件数でもない。全国人数から東京・神奈川の検索市場や自社獲得可能数を推定しない。地域別の検索需要はKeyword Plannerと実際の有効問い合わせで別途把握する。[警察庁](https://www.npa.go.jp/news/release/2026/20260331001.html)

以下は公開サービス構造からの戦略的推論。人口統計から広告CVRや競合シェアを導いたものではない。

| 隣接領域 | 共通する顧客課題 | 活かす戦略 | 限界 |
|---|---|---|---|
| 緊急修理・衛生復旧 | 今すぐ相談先が必要、到着と費用が不明 | 応答率、初動予定、概算と現地確定を区別 | 24時間受付と24時間即応は違う。実態以上の速度を約束しない |
| 遺品整理・葬送 | 家族の心理負担、遠方、複数手配 | 立ち会い不要、担当窓口の一本化、写真報告 | 一般遺品整理の広い広告配信は現方針の対象外 |
| 不動産管理・原状回復 | 入居者苦情、空室期間、所有者への説明 | 工程別見積、現地確認予定、完了報告、紹介元別管理 | 既存の大家グループ2タップは有望仮説であり大量獲得の証明ではない |
| 事故物件売買 | 清掃後に保有・売却を決めたい | 対応できる提携先との連携、清掃範囲と売買を分ける | 自社にない買取機能を広告で約束しない |
| 保険・損害対応 | 費用負担、必要書類、補償範囲 | 写真・作業明細・見積書を整理できる体制を作る | 適用可否は保険会社判断。「保険で無料」と訴求しない |

具体例: アイコムは特殊清掃と事故物件買取を別サイトで接続。ブルークリーンは衛生復旧・環境・不動産管理の複数課題を扱う。損保ジャパンのFAQも、契約と状況次第で原状回復の補償対象となる場合があり、担当者が判断すると説明している。[アイコム](https://kaitori-icom.com/)、[ブルークリーンのサービス](https://b-clean.jp/service/)、[損保ジャパン](https://faq.sompo-japan.jp/sumai/faq_detail.html?id=80420)

短期は検索広告の顕在需要、並行して管理会社との紹介接点、中期は既存の自社サイト・Googleビジネスプロフィールに特殊清掃の事例を蓄積する。紹介・自然検索のCVをGoogle広告CVに合算して広告目標達成と見せない。
