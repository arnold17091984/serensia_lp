# 月30成約に向けた戦略・実行仕様

2026-09-07 / P-9 / T-87。背景・根拠は [調査](02-investigate.md)、前提は [目的](01-intent.md)。

## 1. 採る戦略

**東京・神奈川で、臭い・汚染の状況を相談でき、必要工程と総額を説明し、近隣に配慮して原状回復まで任せられる専門窓口。**

ユーザー確認により最終目標は月30成約。旧版の月30有効問い合わせという前提は撤回する。緊急の遺族・大家と、複数関係者を調整する管理会社を主顧客にする。既存の実写事例・代表対応・明細を使って依頼前の不確実さを減らす。実施順は成約までの計測と予算・施工能力の確認、広告とLPの意図一致、応対・見積営業の改善、検証後の増額。

## 2. 月30成約の必要条件

式: `成約数 = 広告費 / CPC × 有効問い合わせCVR × 有効問い合わせからの成約率`。
有効問い合わせCVRは広告クリックを分母、成約率は有効問い合わせを分母にする。月25万円で30成約なら広告費ベースの受注CPAは8,333円以下が必要。成約率40%なら有効問い合わせCPAは3,333円以下となる。これらは目標予算からの逆算値であり、採算上の許容上限は別に算出する。

| 有効問い合わせからの成約率 | 必要有効相談 | CPC550円・有効CVR4%の広告費 | CPC550円・有効CVR6%の広告費 |
|---|---:|---:|---:|
| 30% | 100件 | 1,375,000円 | 約916,667円 |
| 40% | 75件 | 1,031,250円 | 687,500円 |
| 50% | 60件 | 825,000円 | 550,000円 |
| 60% | 50件 | 687,500円 | 約458,333円 |

550円は直近週572.73円等を参考にした計画仮定。CVR・成約率も業界平均や自社実績ではない。クリック増で単価・検索意図・成約率が変わり得るため、表は達成予測ではない。月25万円・成約率40%では、有効CVR4%で約7.3成約、6%で約10.9成約。30成約には有効CVR16.5%が必要になる。旧版の有効CVR6.6%は30問い合わせの条件であり、30成約には不足する。

広告費1,031,250円、広告費ベースの受注CPA34,375円。この数のクリックを既存地域・上限CPCで確保できるかは未確認。日別の需要とランク・予算の損失を確認する。月30件が継続する安定状態の計画であり、その月の広告費とその月の契約を機械的に割って広告効果を判断しない。問い合わせから契約までの時間差を考慮する。

### 受注利益からの判断

`許容受注CPA = 1件あたり広告費控除前の限界利益 - 成約1件に配賦した営業費 - 残したい利益`。成約に至らなかった見積・現地調査の費用も営業費に含める。売上や、処分費・外注費を控除していない粗利で判断しない。

例えば1件限界利益10万円、広告受注CPA34,375円なら、30成約で広告費控除後は1,968,750円。この金額から営業費・固定費等を負担するため純利益ではない。実際の単価・原価・キャンセル率は未確認。広告費予算と運用・LP制作・計測費は分けて示す。

推奨判断: 月25万円は、現在の成約率を測る検証予算として仮置きする。成約率40%・有効CVR4-6%の実績が確認できた場合、月30成約の比較用予算は約69-103万円になる。即時増額せず、受注CPA・利益・見積対応と施工能力・検索量を確認して段階的に進める。成約率が高ければ必要予算は下がり、低ければ上がる。

## 3. 計測・受付を先に整える

| 段階 | 定義 | 用途 |
|---|---|---|
| タップ | 電話/LINEボタン押下 | LP導線の診断。成果とは別 |
| 通話/メッセージ | 実通話、LINE初回メッセージ | 応対の入口。30秒通話も品質確認が必要 |
| 有効問い合わせ | 地域・案件種別が適合し相談成立 | 成約への中間KPI。40%成約なら75件/月が計画例 |
| 見積 | 現地確認/見積提示 | 営業の進捗 |
| 成約・利益 | 案件単位の契約成立、キャンセル、売上、外注・処分等控除後利益 | 月30成約の最終KPIと投資判断 |

- 案件台帳に発生日、流入、案件ID、現場地域、特殊清掃該当、チャネル、初回返信時間、見積、成約、失注理由を記録。個人情報は必要な業務台帳に限定し、GA4に氏名・住所・現場写真・自由記述を送らない。
- 台帳に見積提示日・金額・契約日・施工予定日・キャンセルも記録。契約日での月次件数と、問い合わせ発生月ごとに追跡した成約率を併記する。新しい未決案件を直ちに失注とせず、古い月の契約を今月の問い合わせで割らない。
- 既存通話アクションを検証。AdsとGA4、電話/LINE、複数タップの二重計上を整理。新たな有効CV計測の記録を確認してからタップをSecondaryにする。
- Primary/Secondaryだけでなくキャンペーン目標・カスタム目標も点検し、タップが意図せず入札対象に残らないようにする。[Google公式](https://support.google.com/google-ads/answer/11461796?hl=ja)
- LINE外部ページへのタップだけで友だち追加・メッセージ送信を推定しない。まず流入経路ラベルと台帳で照合し、必要ならMessaging API等の実装可能性を別途検証する。
- 受付目標案は営業時間内の電話応答率90%以上、LINE一次返信15分以内。不在時の折り返しと夜間の返信時刻を決める。これは社内運用の提案で、現状実績・公開保証ではない。
- 広告からの実通話や問い合わせの試験は担当者と時刻・記録方法を決めて実施し、テスト案件を営業件数から除く。

### 見積営業と施工能力

成約を増やすには、応答・現地確認・見積提示・契約の各段階を測る。初回相談で現場地域、必要作業、希望日、依頼者と決裁者、支払い・見積比較の状況を必要な範囲で確認し、現地確認予定を伝える。見積は緊急の汚染除去、家財処分、消臭、原状回復の範囲と追加・変更時の扱いを明示する。検討中案件は依頼者の希望する方法・時刻で連絡し、失注理由を価格・日程・対応外・他社・連絡不成立などに分ける。成約率向上を値引きだけで作らず、受注利益を併記する。

月30成約を継続する場合は施工も月30件相当を処理する必要がある。1班が1日稼働する量を1班日として、`必要班数 = 切り上げ(30件 × 1件あたり平均班日 / (月稼働可能日 × 現場に割ける割合))`。例えば22日・80%の仮定では、平均1班日/件なら2班、2班日/件なら4班、3班日/件なら6班。80%は移動・段取り等を見込んだ仮定で、人数・現場難易度・並行作業の実態に置き換える。自社実績として必要班数を断定しない。現地見積の担当時間も別に確保する。

## 4. Google広告の構成案

月25万円で最初に検証する場合の配分目安で、月30成約を達成する予算とは位置づけない。最初から全て別キャンペーンに分割せず、既存グループを活用する。グループには独立した日予算がないため、下記は管理配分であり設定値ではない。予算を厳格に分ける必要がある枠のみキャンペーンを分ける。

| 検索意図 | 配分案 | キーワード例 | LPで最初に答えること |
|---|---:|---|---|
| 緊急・業者選定 | 50% / 125,000円 | 特殊清掃 東京、孤独死 清掃 業者、特殊清掃 神奈川 | 対応地域、現地確認、担当者、近隣配慮 |

| 指名・小規模探索 | 上限5% / 12,500円 | 自社名、実績のある専業競合語等 | 自社の差と根拠 |

検索量、有効問い合わせCPA、成約率、受注CPAと利益で配分を調整する。指名の検索量が少ない場合、枠を使い切らない。法人向け15%は13クリック2タップからの探索仮説であり、成約実績予測ではない。

- 開始案は完全一致・フレーズ一致中心。現在のマッチタイプを取得してから差分を決める。検索語句を週次確認する。
- 求人、バイト、年収、就職目的、機材購入等の明確な不適合を除外候補とする。資格・団体名・競合名・費用負担の語は文脈と実問い合わせで判断。サービス不明の車内清掃・ゴミ屋敷・買取も確認対象。
- 所在地中心の地域設定を基本案にする一方、遠方の遺族が東京・神奈川の現場を相談する需要を失わないよう、明示地域語の遠方枠を小さく別検証する。検索者所在地と現場所在地を区別する。[地域設定](https://support.google.com/google-ads/answer/1722038?hl=ja)
- 上限CPC650円は当面維持。品質・検索意図・LP・応答を改善してから、ランク損失と利益に基づき再検討する。
- 通話アセットの掲載時間は実際の応答体制に合わせる。既存スケジュール行を安易に削除しない。少数CVから金曜だけに寄せない。
- 計測が整う前のPMax・広範な自動拡張を初手にしない。十分な質のCVが継続して入り、基準期間と比較できる状態で入札戦略の実験を設計する。必須CV数の架空の基準を設けない。
- 事故・死別という文脈を利用した追跡型配信を今回の基本案にしない。実施を検討する際は対象カテゴリと現行ポリシーを確認する。[Googleのパーソナライズド広告データ利用](https://support.google.com/adspolicy/answer/6242605?hl=ja)

## 5. LPの優先改善仕様

全面刷新せず、既存の緑・金・赤、代表写真、CTA、実写事例を活かす。

1. **料金検索に答える上部ブロック。** FVとCTAの後に、軽度/浴室/重度の実在3事例を簡潔に掲載。既存15万・20万・33万円等から内容を確認して選ぶ。最低5万円の条件と各総額の作業範囲を並べる。最初に全事例を長く展開しない。
2. **特殊清掃に合う相談文。** LINEの文例を「特殊清掃の相談です。現場は○○市、間取り○○、現地確認希望です」等にする。写真は任意とし、相談のために現場へ入ることを求めない。
3. **結果の証拠。** 事例に現場条件、工程、期間、総額、完了確認方法を記録。許諾済み特殊清掃の声を追加できれば掲載。既存の遺品整理口コミを特殊清掃口コミとして書き換えない。
4. **法人の入口。** 既存自社サイトの法人ページを確認した上で、広告LP内に大家・管理会社向け要約を設ける。報告書や保険向け明細は、作成できることを確認してから訴求。
5. **長い説明の位置。** 料金ブロックの検証後に漫画・工程・事例の展開順を検討する。既に漫画後半は折り畳まれているため、「折り畳み新設」を既存未実装として扱わない。
6. **表記の整合。** 自社サイトとの定休日・対応地域・メール入口、レビュー件数と掲載時点、料金の税区分を一致させる。

最終評価は成約数・受注CPA・利益。有効問い合わせCVRを先行指標、価格アンカー利用・料金到達・チャネル別タップ率を診断指標とする。安い問い合わせが増えても成約率が落ちた場合は改善成功としない。CVが少ない間に多数のABパターンを並走させない。週1つの大きな変更を基本とし、変更前後で検索語句・曜日構成・広告配分も確認する。100クリック未満や少数CVで勝者を断定せず、試験期間・母数・問い合わせ品質を報告する。

## 8. 最終的な判断に必要な回答

月30成約という目標は確定済み。最新月予算、直近の有効相談・見積・成約数、平均受注額・案件利益、施工能力と達成期限は未確認。成約率40%なら「月25万円では有効CVR16.5%が必要」「有効CVR4-6%なら約69-103万円を比較」「不足を紹介経由の成約で補うなら別チャネル目標として計画」を判断する。紹介を含めた全体30成約はGoogle広告起点30成約とは異なるため、合算して広告目標達成と報告しない。
