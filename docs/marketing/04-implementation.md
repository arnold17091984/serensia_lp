2. 相談導線: LINEに写真不要の相談文例、写真のための入室は求めない。既存電話・LINEとgtagイベントを維持する。
3. 法人導線: 既存の立ち会い不要・鍵預かり・写真報告等を短くまとめる。未確認の保険申請代行・新規保証・返信時間は追加しない。
4. 内部資料: docs/marketing/improvement-plan.html に概要・事実/仮説・競合比較・施策・30成約シミュレーター・90日計画・出典を実装。単体で閲覧できること。公開LPへ内部広告費・戦略を載せない。

6. 検証: build、型、mobile/desktop、価格・アンカー・新規イベント・LINE文例、HTMLシミュレーターの境界値と印刷を検証。独立QAの証跡をボードに記録。
7. 公開: 既存VPS設定で接続確認、更新前の退避とデプロイ差分確認を行い、QA済みLPのみ公開。内部HTML・台帳はdocs下に置き公開しない。接続不可なら静的ビルドとローカルプレビューまで完成させる。

## 受入基準

- 料金事例3件は既存の実在データを再利用。全6事例の価格と作業は維持し、重複した金額定義を避ける。
- 最低5万円と事例価格の対象を混同させない。税込/税別・新規の工期・保証・資格・口コミを推測で足さない。
- 緑/金と赤の電話CTAを維持。既存の上部CTAを押し下げずに料金要約を漫画前へ置く。
- 新規セクションはdata-section、新規CTAはdata-gtmを付け、既存の単一イベント委譲で測る。成約イベントをタップから捏造しない。
- 新規要素に横はみ出し・文字の重なりがなく、キーボード操作できる。
- 新規HTMLは月30成約を主指標とし、仮定のCPC550円/有効CVR4%/成約率40%で75相談・30成約・広告費1,031,250円。0/空/不正入力では誤った達成表示をしない。
- 本番のLPと内部計画書で完了・未実施のステータスを正しく区別する。
