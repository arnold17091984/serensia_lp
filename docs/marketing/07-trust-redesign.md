# 信用と相談判断を軸にしたLPの再設計

2026-09-08 / T-97 / P-9

ユーザーの「マーケティング的にも顧客的にも信用がおけるデザインに抜本的に見直す。ダサくするという意味ではない」という依頼に対応。過去の全面刷新見送りを更新し、深緑基調・赤い電話CTAは維持する。

## 情報とデザイン

- 画像に焼き込まれた見出しをHTMLへ変更。代表の既存実写、対応地域、特殊清掃・消臭・遺品整理の範囲を冒頭に掲載。
- 白と淡い緑を背景に、深緑の見出しと帯、控えめな金の線を使用。明朝は主要見出しと人名、ゴシックは本文・操作に使用。本文15〜16px、操作文言14px以上を基本とし、補足は12〜14px。主要見出しは明示的な改行で構成し、auto-phraseに依存しない。
- PCは幅1120pxの内容領域、スマホは1列。スマホでは電話・LINEを代表紹介より先に表示。料金事例はPC3列、タブレット2列、スマホ1列。
- 5万円〜は空間除菌・消毒のみの簡易対応であることを金額の直下に明記。体液除去を伴う15万円〜と並べ、最低価格だけで期待を作らない。
- 既存6事例の金額、作業内容、価格変動要因、写真を再利用。作業内容の詳細は開閉式。作業前の写真は内容への注意を添えた別の開閉式にして、不意に汚染写真を見せない。
- 会社名、所在地、代表、既存の資格・許可番号・保険情報をまとめ、会社概要へ接続。新しい実績数・口コミ・保証は追加していない。
- 相談→現地確認・見積り→納得して契約→作業と報告の順序を示す。LINEは写真なしでも相談でき、24時間受付は即時返信の保証と区別する。
- 繰り返しの大型CTA、漫画、装飾バッジ、英字ウォーターマーク、口コミモーダルはトップページの表示から外す。既存コンポーネント自体は今回の対象外として残す。

## 実装と計測

`components/trust/trust-landing.tsx` とCSS Moduleに表示を集約。料金は `components/mcy/pricing-data.ts`、FAQは `components/mcy/faq-data.ts` に既存データを移動。FAQの表示とJSON-LDは同じデータを参照する。

`McyTracking.tsx` と `PhoneHoursNotice.tsx` の処理は変更なし。gtag直送信、電話/LINEの実連絡先、JSTの9〜21時判定を維持。追従CTAの外観だけを簡素化する。

主要CTAは `cta_tel_fv` / `cta_line_fv` / `cta_tel_section` / `cta_line_section` / `cta_tel_footer` / `cta_tel_sticky` / `cta_line_sticky` を保持。削除した旧セクションのCTA IDは今後送信されない。セクション到達は `hero` / `service` / `pricing` / `trust` / `flow` / `faq` / `contact`。再構成前後でスクロール深度やCTA件数を単純比較しない。

## 検証

- `npm run build`：型検証と静的書き出しを含め成功。トップページ First Load JS 105kB。
- `node output/playwright/verify.cjs`：ローカル静的書き出しをChromiumで検証。`VERIFY_ENGINE=webkit node output/playwright/verify.cjs` でWebKit 26.4も同じ項目を通過。両エンジンともコンソール/実行時エラー0。320/390/768/1024/1440pxで全詳細展開時も横はみ出し0。h1/h2は全幅で指定行数。
- 6事例、FAQ9件とJSON-LDの一致、画像15枚の読み込み、内部アンカー、会社概要/プライバシー/法的表記のHTTP 200を確認。
- 作業詳細と作業前写真の段階的表示、FAQのキーボード開閉、電話とLINEの各1回のイベント発火、touch端末の電話分類、追従バーの表示/非表示、JST 21時と9時の受付表示切り替えを確認。
- 主要配色のコントラスト：本文11.52:1、補足本文5.84:1、小見出し5.36:1、電話CTA6.05:1、LINE CTA7.00:1。
- ブラウザ検証ではGoogleの外部スクリプトをローカルで代替し、実広告・分析への送信を防止。実機iOS Safari、実際の通話発信、LINE友だち追加、Googleの転送番号置換は検証対象外。

証跡はこのworktreeの `output/playwright/` に保存（検証スクリプト、JSON結果、PC/スマホのスクリーンショット）。コミットには含めない。本番公開、広告設定変更、成約率改善の実証はこの実装の完了には含まない。
