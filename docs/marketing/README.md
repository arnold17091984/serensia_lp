# セレンシア: 月30成約への戦略

2026-09-07 / P-9 / T-87

## 推奨方針

ユーザー確認により、目標は**問い合わせ30件ではなく月30成約**。東京・神奈川の特殊清掃を主軸に、**必要工程・総額・担当者・原状回復までの見通しを示す**。既存LPの代表写真、近隣配慮、立ち会い不要、料金付き施工事例を活かす。優先順は「成約までの計測・予算・施工能力の確認 → 料金・相談導線 → 検索意図別広告・応答・見積営業の改善 → 検証後に増額」。

## 現状と目標の差

8月の既存広告レポートでは273,594円・574クリック・6タップ、タップCPA45,599円。問い合わせや成約の件数ではない。実際の成約数と受注CPAは不明。月25万円で30成約なら、広告費ベースの受注CPAは8,333円以下が必要。

| 有効問い合わせからの成約率 | 30成約の必要有効相談 | 広告費: 有効CVR4% | 広告費: 有効CVR6% |
|---|---:|---:|---:|
| 30% | 100件 | 約137.5万円 | 約91.7万円 |
| 40% | 75件 | 約103.1万円 | 約68.8万円 |
| 50% | 60件 | 約82.5万円 | 約55万円 |
| 60% | 50件 | 約68.8万円 | 約45.8万円 |

CPC550円を仮定した条件計算で、業界平均や達成予測ではない。有効CVRは広告クリックから有効問い合わせへの率。計画例は1,875クリック → 有効相談75件 → 見積60件 → 成約30件（有効CVR4%、見積化80%、見積から成約50%）で、広告費1,031,250円・受注CPA34,375円。月25万円では同条件で約7成約。月25万円を維持して30成約にするには、成約率40%で有効CVR16.5%が必要となる。

まず実際の成約率・受注利益・検索需要・施工能力を確認する。約69-103万円は成約率40%・有効CVR4-6%の場合の比較用予算で、即時増額の推奨ではない。広告以外の紹介で補う案は別チャネルの成約として管理する。

## 重要な発見

- 9月の既存レポートは広告APIの取得障害を記録。最新成績は不明で、欠測をCVゼロと解釈しない。
- 9/1の設定報告は日予算15,000円。一定なら通常の月換算456,000円で、資料上の月25万円と整合確認が必要。
- 遺品整理の8月費用75,447円は停止前を含む。直近8/24-30は0円なので、現在も浪費しているとは言えない。
- スマホCTAは最初の画面内。料金詳細は約10,500px下にあり、料金付き代表事例を上部に出す検証を優先。
- 掲載口コミは遺品整理中心。特殊清掃の消臭結果・総額・期間を示す証拠を強化する。
- 大家・管理会社の2タップ/13クリックは探索の理由になるが、大幅増額を正当化するほどの母数ではない。
