# 広告案と成約管理

2026-09-08 / P-9。月30成約を最終目標とする。

## 広告案

`ads-draft.csv` は既存の約束の範囲で作成したRSA素案。誤配信を避けるため全行Paused。自動入稿したファイルではなく、既存のキャンペーン・広告グループ名、アカウントの言語とEditorの列マッピングに合わせて確認する入力資料。新しい広告グループ名は案であり実在を意味しない。

最新設定を取得して差分を確認できるまで、既存広告の置換・有効化・予算変更はしない。最終URLの料金・法人アンカーは公開確認後に選択する。一般遺品整理を再開せず、上限CPC650円を維持する。

## 台帳

`contracts-template.csv` は見出しのみの空台帳。実績を捏造したサンプル行はない。案件IDは同一の現場依頼を電話・LINEで共有し、氏名・番地・自由記述・写真・広告クリックID等の個人情報をこの共有テンプレートへ入れない。

- 流入チャネル: Google広告 / 自然検索 / 紹介 / その他 / 不明。複数流入の扱いは運用で統一する。
- 有効相談: 対応地域内で特殊清掃について相談が成立したら「はい」。営業、求人、誤電話、対応外は「いいえ」。
- ステータス: 相談 / 見積予定 / 見積提示 / 成約 / 施工完了 / 失注 / キャンセル。
- 契約日での月次成約数と、初回相談月ごとに追った成約率は別集計。同月費用と同月契約だけで広告効果を断定しない。
- 同一案件の特殊清掃と遺品整理のセットを2成約に数えない。キャンセルは別記して純成約を補正する。
- 限界利益は契約額から処分・外注・その他変動費を控除。広告費・失注を含む営業費・固定費控除前かを明示する。

## 検索語句の確認順

求人・バイト・就職・機材購入など明確な不適合を先に点検。「費用」「誰が払う」「専業競合名」は依頼直前の比較もあり、一括除外しない。既存CVがある団体名・特殊清掃センターも除外しない。現場の対応範囲が未確認の地域や車内清掃は保留欄へ分ける。

最新データ欠測時は空欄とし、費用や成約を0と報告しない。無応答、LINE未送信、見積辞退と広告の検索意図不適合を分けて改善する。
