# セレンシア キービジュアル再現

## ファイル
- `index.html`：HTML/CSS + 画像素材で再構築したKV
- `pixel-perfect.html`：見た目完全一致確認用。元KV画像を背景にし、電話/LINEクリック領域を配置
- `assets/`：使用画像
- `css/kv.css`：スタイル

## 実装方針
- 見出し、CTA文言、実績表示、悩みリストはHTMLテキスト
- ロゴ、人物写真、部屋写真は画像
- LINEはブランドカラー寄りの緑
- CVボタンに赤は使わず、電話CTAは明るいブルーグリーン
- 赤/オレンジは見出し強調・非CV部分のみに使用
